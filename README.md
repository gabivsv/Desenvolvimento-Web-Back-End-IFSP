# 💻 Desenvolvimento Web Back-End — IFSP

Repositório dedicado às atividades e projetos desenvolvidos na disciplina de **Desenvolvimento Web Back-End** do curso de **Análise e Desenvolvimento de Sistemas — IFSP**.

O conteúdo reúne exercícios, experimentos e projetos desenvolvidos ao longo da disciplina, explorando diferentes conceitos relacionados ao desenvolvimento de aplicações back-end.

## 🧠 Conteúdos

* Desenvolvimento de aplicações back-end
* APIs e integração de sistemas
* GraphQL
* Arquitetura e organização de aplicações
* Processamento e comunicação entre componentes
* Conceitos relacionados a sistemas web

## 🛠️ Tecnologias

* Java
* Spring Boot
* GraphQL
* Git e GitHub
